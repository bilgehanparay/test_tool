## About test_tool
a simple tui tool to parse run gtest executables

## WebAssembly Demo

Try the live WebAssembly demo:
- Main: [https://bilgehanparay.github.io/test_tool/](https://bilgehanparay.github.io/test_tool/)
- Develop: [https://bilgehanparay.github.io/test_tool/develop/](https://bilgehanparay.github.io/test_tool/develop/)
